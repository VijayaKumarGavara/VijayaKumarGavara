## Featured Projects

### 🌾 [Dhanya Sethu — Agri Procurement & Payment Tracking](https://github.com/VijayaKumarGavara/Dhanya---Sethu-Production)
> Node.js · Express.js · MongoDB · React.js · Redux · Tailwind CSS · Cloudinary · JWT

A production-deployed, full-stack multi-role platform digitizing agri-procurement between farmers, buyers, and admins.

- Designed and shipped **15+ RESTful APIs** covering procurement workflows, approval chains, and payment settlement
- Implemented **JWT authentication + RBAC** to enforce role-level permissions across 3 user types
- Modelled MongoDB collections for procurement entries, payment records, and audit logs with data consistency across concurrent operations
- Built responsive React dashboards with real-time procurement status tracking and payment update feeds

🔗 [Live Demo](https://dhanya-sethu.netlify.app) &nbsp;|&nbsp; [GitHub Frontend](https://github.com/VijayaKumarGavara/ds-v2-frontend) &nbsp;|&nbsp; [GitHub Backend](https://github.com/VijayaKumarGavara/ds-v2-backend)

A browser-based SQL learning tool with live query execution, real-time result rendering, and an AI-powered hint system.
